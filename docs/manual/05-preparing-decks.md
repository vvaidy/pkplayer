# Preparing decks

Send this page to your presenters.

## The short version

- **Send a PDF.** Not Keynote, PowerPoint or a link.
- **20 slides.** Extra pages will not be shown.
- **16:9 (widescreen).** Other shapes work but get black bars.
- **No animations, builds, transitions, video or sound.** A PDF is one still image per page.
- **No speaker notes, handouts or hidden slides in the export.**
- Each slide is on screen for **20 seconds** and advances by itself. You can't click ahead.

## Exporting a PDF

| App | Steps |
| --- | --- |
| **Keynote** | File → Export To → PDF. Choose *Image Quality: Best*. **Untick** *Print each stage of builds*, *Include presenter notes* and *Include skipped slides*. |
| **PowerPoint (Mac)** | File → Export… → File Format: PDF. Make sure the layout is *Slides*, not *Notes* or *Handouts*. |
| **PowerPoint (Windows)** | File → Export → Create PDF/XPS → Options… → Publish what: *Slides*; untick *Include hidden slides*. |
| **Google Slides** | File → Download → PDF document (.pdf). Skipped slides are left out automatically. |
| **Canva** | Share → Download → File type: *PDF Standard* (or *PDF Print* for photo-heavy decks). |

Then open the PDF and check: one page per slide, 20 pages, nothing missing.

## Why each rule matters

**Builds and animations.** A PDF has no animation. Exporting "each stage of builds" turns one animated slide into several pages, which pushes your real slides past page 20 — and those get cut. Design each slide as a single still.

**Page count.** PK Player shows at most *Max slides* pages (usually 20) and silently moves on to the next presenter. If your deck is short — say 15 pages — it just ends early.

**Aspect ratio.** Slides are scaled to fit the screen without cropping. A 4:3 deck on a 16:9 projector gets black bars on the sides. Use the template's widescreen option.

**Fonts.** PDF export embeds fonts, so slides look the same on the event laptop as on yours. If a slide looks wrong in the PDF, it'll look wrong on the night too — check the PDF, not the original.

**Images.** Use images at least 1920 pixels wide for full-screen photos. Small images exported at low quality look soft on a projector. Very large decks (hundreds of MB) still work but take longer to load — keep under ~50 MB if you can.

## For organisers

- Name the files with the presenter's name, e.g. `03-asha-tiny-gardens.pdf`. The file name is what the player shows on the Play screen.
- Drop each deck into your event when it arrives and look for yellow badges (**only first 20 play**, **only 17 slides**, **4:3, most are 16:9**) or the red **Unreadable PDF**. The summary line counts them: **2 decks need a look**.
- Want to try the format first? The repository's `samples/demo/` folder has four ready-made decks.
